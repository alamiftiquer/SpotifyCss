# Spotify Web Player Clone

A static, responsive front-end clone of the Spotify Web Player user interface built using HTML and CSS. 

## 🎵 Overview

This project is a UI reproduction of the popular music streaming platform, Spotify. It demonstrates modern web layout techniques using CSS Flexbox, sticky positioning, and responsive design principles to create a familiar and user-friendly interface.

## ✨ Features

*   **Sidebar Navigation:** Includes standard Spotify navigation links (Home, Search) and a "Your Library" section with promotional call-to-action boxes.
*   **Main Content Area:** 
    *   Sticky top navigation bar with user profile and app install prompts.
    *   Scrollable content displaying various music categories (Recently played, Trending, Featured Charts).
    *   Stylized music cards with hover-ready designs.
*   **Music Player Bar:** Fixed bottom player containing:
    *   Currently playing track information (album art, title, artist).
    *   Playback controls (play, pause, skip) and a styled progress bar.
    *   Volume and additional device controls.


## 🛠️ Technologies Used

*   **HTML5:** Semantic structure and layout.
*   **CSS3:** Styling, Flexbox, custom form inputs (sliders), and media queries.
*   **Font Awesome:** Used for scalable vector icons throughout the interface.
*   **Google Fonts:** Specifically the "Montserrat" font to closely match Spotify's typography.

## 🚀 Getting Started

Since this is a static website, no build steps or local servers are required to view it.

1.  Clone this repository or download the source files.
2.  Ensure you have the `assets` folder in the same directory, containing all the referenced images and icons.
3.  Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).

## 📁 Project Structure

*   `index.html`: The main HTML document containing the structure of the web page.
*   `style.css`: The stylesheet containing all layout and design rules.
*   `assets/`: (Directory) Contains all images, album covers, and custom icons used in the project.
